# Загрузка и распаковка архива
Сначала необходимо скачать архив. Далее его необходимо распаковать в удобную папку.
# Импорт проекта в IDE
Далее открываем удобную IDE, и импортируем проект.
На примере Eclipse:
В левом верхнем углу File -> Open Projects from File System...
Там выбираете в качестве папки - папку проекта. После этого нажимаете finish.
Далее необходимо импортировать jdbc драйверы в проект в IDE.
В IDE Eclipse необходимо сделать следующие действия:
1) Нажать правой кнопкой мыши по проекту в панели слева
2) Выбрать Properties
3) Найти слева Java Build Path
4) Открыть окно Libraries
5) Нажать Add External JARs...
6) Выбрать jaybird-5.0.12.java8jar
7) Выбрать postgresql-42.7.10.jar
В IDE Intelllij idea
1) По аналогии импортируем проект
2) Modules -> Dependencies, и там загрузить 2 jar файла: 
3) jaybird-5.0.12.java8jar
4) postgresql-42.7.10.jar
# Создание базы данных 
Для PostgreSQL базу данных создавать не нужно, достаточно к ней подключиться, приложение это сделает само автоматически.
Для Firebird/RDBExpert:
Если Firebird уже был скачан и установлен, то выбираем подключение, которое работает с локальным сервером и далее будем запускать скрипты для создания таблиц
Если Firebird не был скачан и установлен, то
1) Скачиваем сервер с официального сайта https://firebirdsql.org/en/downloads/ (может не работать без способов обхода)
2) Выбираем там Firebird-3.0.14.33856-0
3) Осуществляем установку так, как удобно, главное запомнить Пользователя и пароль. (в моем случае это sysdba и masterkey соответственно)
4) Заходим в RDBExpert, нажимаем создать подключение
5) Выбираем имя сервера localhost
6) Порт 3050
7) Справа - пользователь (который вы указали при установке Firebird), в моем случае sysdba
8) Чуть ниже справа - пароль, который вы указали при установке, в моем случае masterkey, нажимаем сохранить пароль и далее в самом низу нажимаем подключиться
После того как создали подключение нажимаем выполнить SQL скрипт из файла, нажимаем "Обзор"
Выбираем папку с проектом, и в ней папку REDBD Data Base
Там по очереди запускаем скрипты (они подписаны в нужной последовательности)
После этого можно вернуться в IDE и запустить приложение
